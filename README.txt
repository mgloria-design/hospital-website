INNOVA HOSPITAL WEBSITE
=======================

Pages
-----
index.html        Home
services.html     Services
team.html         Our team
admissions.html   Admissions
book.html         Book an appointment
contact.html      Contact

Shared files
------------
styles.css        All colours and layout (red and white, Open Sans)
app.js            Mobile menu and the appointment form
*.jpg             Hospital photos (doctor, reception, dental unit, pharmacy)

How to view it
--------------
Keep all files in the same folder and double-click index.html.
An internet connection is needed to load the Open Sans font.

How to put it online
--------------------
Upload the whole folder to any web hosting, keeping the files together.
Make index.html the home page.

Things to know
--------------
1. Phone number: +254 713 187 220 appears on every page. To change it,
   use search and replace in a code editor across all .html files and app.js.
2. Brand colours are at the top of styles.css (--red, --red-deep, --red-tint).
3. The appointment form on book.html does not send requests yet. It shows
   the patient a summary and tells them to call or visit. Sending requests to
   the hospital needs a small backend or a form service, which can be added.
4. The signs in the photos read "Inova Healthcare" while the site says
   "Innova Hospital". Confirm the correct spelling with the client.
